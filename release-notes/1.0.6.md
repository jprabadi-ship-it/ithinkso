## 追加

- **「許可の状態」の画面を足しました。** I think so に要る許可は、システム設定の2か所（「入力監視」と「アクセシビリティ」）に分かれています。それぞれが本当に許可されているかを ✓ / ✗ で表示し、「設定を開く」で該当する設定へ直接移れます。メニューの「許可の状態…」から開けます。許可が足りないときは、起動時に自動で開き、メニューにも ⚠️ が付きます。
- **「許可をリセットしてやり直す」ボタンを付けました。** システム設定ではオンに見えるのに、裏で許可が「拒否」のまま残り、黙って動かなくなることがありました（打ち直しのキーを送る許可は「アクセシビリティ」の一覧に一緒に表示されるため、画面では見分けられません）。このボタンは I think so の許可だけを消し、起動し直して許可を求め直します。ほかのアプリの許可には触れません。
- 許可をオンにしたあとは、画面の「I think so を再起動」で反映できます。
