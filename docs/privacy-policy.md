## 日本語

### 収集する情報

本アプリは、いかなる個人情報も収集しません。

### キーボード入力の取り扱い

本アプリは打ち間違い救済機能のために、macOS の「入力監視」権限を
用いてキーボード入力を監視します。入力内容の取り扱いは以下の通りです。

- 直近に打鍵された文字列は、打ち直しのためにメモリ上の一時バッファに
  のみ保持されます
- バッファはスペース・Enter・Escape・修飾キー操作のたびに破棄されます
- 入力内容がディスクに保存されることはありません
- 入力内容が外部に送信されることはありません。本アプリには
  ネットワーク通信機能そのものが存在しません

### 第三者への提供

本アプリはいかなるデータも第三者に提供しません。

## English

### Information We Collect

This app collects no personal information of any kind.

### Handling of Keyboard Input

To provide its retype-rescue feature, the app monitors keyboard input
using the macOS Input Monitoring permission:

- The most recent run of typed characters is held only in an in-memory
  buffer, solely so it can be retyped.
- The buffer is discarded on every Space, Return, Escape, or modifier
  key press.
- Typed content is never written to disk.
- Typed content is never transmitted anywhere. The app contains no
  networking capability whatsoever.

### Third Parties

No data is shared with any third party.
