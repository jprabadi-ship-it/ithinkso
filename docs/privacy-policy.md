## 日本語

### 収集する情報

本アプリは、いかなる個人情報も収集しません。

### キーボード入力の取り扱い

本アプリは打ち間違い救済機能のために、macOS の「入力監視」権限を
用いてキーボード入力を監視します。入力内容の取り扱いは以下の通りです。

- 直近に打鍵された文字列は、打ち直しのためにメモリ上の一時バッファに
  のみ保持されます
- バッファはスペース・Enter・Escape・修飾キー操作・マウスのクリック・
  アプリの切り替えのたびに破棄されます
- 入力内容がディスクに保存されることはありません
- 入力内容が外部に送信されることはありません

### 更新の確認

本アプリが行う通信は、更新の確認だけです（バージョン 1.0.4 以降。
それまでの版は通信を行いません）。

- 起動の数秒後に、gigowat.com へ最新版の情報を1回問い合わせます。
  送るのはアプリ名だけで、入力内容・設定・利用状況は送りません
- 新しい版がある場合は、インストールするかを必ず確認します。
  同意した場合にだけ、GitHub から配布ファイルをダウンロードします
- 通常のインターネット通信と同じく、接続先（gigowat.com と GitHub）には
  接続元の IP アドレスが届きます
- インターネットに接続していなくても、更新の確認以外の機能は
  すべて同じように動作します

### 第三者への提供

本アプリはいかなるデータも第三者に提供しません。

## English

### Information We Collect

This app collects no personal information of any kind.

### Handling of Keyboard Input

To provide its retype-rescue feature, the app monitors keyboard input
using the macOS Input Monitoring permission:

- The most recent run of typed characters is held only in an in-memory
  buffer, solely so it can be retyped.
- The buffer is discarded on every Space, Return, Escape, or modifier
  key press, on every mouse click, and whenever you switch apps.
- Typed content is never written to disk.
- Typed content is never transmitted anywhere.

### Update Check

The only network activity is the update check (version 1.0.4 and later;
earlier versions make no network connections).

- A few seconds after launch, the app fetches the latest version
  information from gigowat.com once. It sends nothing but the app name;
  typed text, settings and usage data are never sent.
- If a newer version exists, the app always asks before installing, and
  downloads the installer from GitHub only if you agree.
- As with any internet connection, the servers contacted (gigowat.com
  and GitHub) receive your IP address.
- Without an internet connection, every feature other than the update
  check works exactly the same.

### Third Parties

No data is shared with any third party.
