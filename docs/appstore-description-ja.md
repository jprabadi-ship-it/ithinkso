# App Store 掲載情報（日本語・下書き）

## アプリ名
I think so – 打ち間違い救済

## サブタイトル（30文字以内）
入力モードの打ち間違いを、かな2度押しで打ち直し

## 説明文

「日本語のつもりが sonocheckma-ku...」「英語のつもりが ぎtこみt」——
入力モードの切り替え忘れは、気づいた時にはもう手遅れ。
削除して、切り替えて、もう一度打ち直す。その数秒が積もっていきます。

I think so は、その打ち直しを「かなキー2度押し」ひとつで肩代わりする
メニューバー常駐アプリです。

### できること

- 英語モードで打ってしまった日本語ローマ字を、削除して日本語として
  打ち直します。ライブ変換にもそのまま乗るので、漢字変換まで進みます
- 文中の英単語（check、div など）は英語のまま残します。
  「そのcheckマークはどこまでが範囲ですか」のような混在文も一度で復元
- 日本語モードで打ってしまった英語は、打った通りのローマ字に戻して
  英語モードに切り替えます
- 方向は自動判定。覚える操作は「かなキー2度押し」だけ

### 動作の仕組みとプライバシー

- キーボード入力の監視には macOS の「入力監視」権限、打ち直しの
  イベント送出には「アクセシビリティ」権限を使用します
- 入力内容はメモリ上の一時バッファでのみ扱い、ディスク保存・
  外部送信は一切行いません。ネットワーク通信機能自体がありません
- スペースや Enter、コマンドキー操作でバッファは都度破棄されます

### 動作環境

- macOS 13 以降
- 日本語入力（ローマ字入力）+ JIS 配列の「かな」キー
  （US 配列では Karabiner-Elements 等でかなキーを割り当てて利用できます）
