# App Store 掲載情報（日本語・下書き）

## アプリ名
I think so – 打ち間違い救済

## サブタイトル（30文字以内）
入力モードの打ち間違いを、コマンド2度押しで打ち直し

## プロモーション用テキスト（170文字以内）

※ App Store Connect のこの欄は ⌘（U+2318）を「無効な文字」として弾く。
  「コマンドキー」と書くこと。概要欄は ⌘ を通す。

入力モードを間違えて打ってしまった文字列を、右コマンドキーの2度押しで正しく打ち直します。文中の英単語はそのまま、ローマ字のタイポも直します。逆方向は左コマンドキーの2度押しです。

## 説明文

「日本語のつもりが sonocheckma-ku...」「英語のつもりが ぎtこみt」——
入力モードの切り替え忘れは、気づいた時にはもう手遅れ。
削除して、切り替えて、もう一度打ち直す。その数秒が積もっていきます。

I think so は、その打ち直しを「コマンドキーの2度押し」ひとつで肩代わりするメニューバー常駐アプリです。

■ できること
・英語モードで打ってしまった日本語ローマ字は、右コマンドキーを2度押し。削除して日本語として打ち直します。ライブ変換にもそのまま乗るので、漢字変換まで進みます
・文中の英単語（check、div など）は英語のまま残します。「そのcheckマークはどこまでが範囲ですか」のような混在文も一度で復元します
・ローマ字を打ち間違えていた場合も検出して修復します
・日本語モードで打ってしまった英語は、左コマンドキーの2度押し。打った通りのローマ字に戻して英語モードに切り替えます
・覚える操作は「右⌘×2 で日本語へ、左⌘×2 で英語へ」の2つだけ。JIS 配列ならかな/英数キーの2度押しでも同じで、行きたいモードのキーを2回押すだけです

■ 動作の仕組みとプライバシー
・キーボード入力の監視には macOS の「入力監視」権限、打ち直しのイベント送出には「アクセシビリティ」権限を使用します
・入力内容はメモリ上の一時バッファでのみ扱い、ディスク保存・外部送信は一切行いません。ネットワーク通信機能自体がありません
・スペースや Enter、修飾キー操作のたびにバッファは破棄されます

■ 動作環境
・macOS 13 以降
・日本語入力（ローマ字入力）が有効になっていること
・キーボード配列は問いません（コマンドキーはどの配列にもあります）
