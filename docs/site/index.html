I think so は、入力モードを間違えて打ってしまった文字列を、かなキーの2度押しで 正しいモードに打ち直す macOS 用のメニューバーアプリです。 キーボード入力を監視しますが、その内容が端末の外に出ることはありません。

01キーボード入力の取り扱い

打ち間違いを打ち直すという機能の性質上、本アプリは macOS の「入力監視」権限を用いて キーボード入力を監視します。取り扱いは以下に限られます。

  • 直近に打鍵された文字列を、打ち直しのためにメモリ上の一時バッファにのみ保持します
  • バッファはスペース・Enter・Escape・修飾キー操作のたびに破棄されます
  • 入力内容がディスクに保存されることはありません
  • 入力内容が外部に送信されることはありません。本アプリにはネットワーク通信の機能自体がありません

02必要な権限

初回起動時に2つの許可を求めます。どちらも中核機能の実行に必要です。

  • 入力監視
    かなキーの2度押しの検出と、直前に打った文字列の記憶に使用します
  • アクセシビリティ
    打ち直しのためにキー入力イベントを送出します。システム設定では「アクセシビリティ」と表示されますが、使用するのはイベント送出の機能のみで、他アプリの画面内容を読み取ることはありません

許可を与えた後はアプリの再起動が必要です。許可しただけでは反映されません。

03使い方

入力モードを間違えて打ってしまったら、かな キーを素早く2回押してください。方向は自動で判定されます。

英語モードのまま日本語を打ってしまったとき

sonocheckma-kuhadokomadegahannidesuka
そのcheckマークはどこまでが範囲ですか

文中の英単語はそのまま残ります。ローマ字を打ち間違えていた場合も検出して直します。

日本語モードのまま英語を打ってしまったとき

ぎtこっみt
gitcommit

04よくある質問

  • 反応しない
    メニューバーのアイコンから権限が付与されているか確認してください。許可した直後はアプリの再起動が必要です
  • かなキーがないキーボードを使っている
    JIS 配列の「かな」キー（キーコード 104）を使用します。US 配列の場合は Karabiner-Elements などで任意のキーに割り当ててください
  • Caps Lock は使えなくなる？
    いいえ。Caps Lock には一切干渉しません

English Summary

Privacy

I think so collects no personal information. To provide its retype-rescue feature it monitors keyboard input via the macOS Input Monitoring permission, but the most recent run of typed characters is held only in an in-memory buffer, is discarded on every Space / Return / Escape / modifier key press, is never written to disk, and is never transmitted anywhere. The app contains no networking capability. No data is shared with any third party.

Permissions

Input Monitoring — to detect the kana-key double press and remember the characters you just typed. Accessibility — to post the keystrokes that perform the retype. Only the event-posting capability gated by this permission is used; the app does not read the UI contents of other applications. Restart the app after granting permissions.

How to use

When you type in the wrong input mode, press the kana key twice quickly. The text you just typed is deleted and retyped in the correct input mode. The direction is detected automatically.
